# Sweets v062 便意识别

只支持用户指定的 `fw_tg18_jp_v062_2019-09-12_sweets.bin`。直接读取模拟器 SRAM 的当前状态；前台使用应用内提醒及短提示音，后台使用 iOS 本地系统通知。没有后台预测。

关键指令：

- `0x20154a84` 起：参数 `+0x40` 的消化计数累积到两次后，
  `0x20154aa6..0x20154aaa` 将 20 写到 `+0x26`。这不是按现实时间猜测的定时提醒。
- SRAM `0xf8005696..0xf800569c`：倒计时减一；到零后
  `0xf80056b0` 调用 `0x201543c0`，后者在 `0x201543ec..0x201543f6`

## 实现及复验

`potty::PottyProfile` 在加载 ROM 时匹配代码指纹，只读 SRAM；C ABI
`pm_potty_seconds` 返回 `-1`（不支持或当前不可用）、`0`（无便意）、
`1..20`（当前倒计时）。深度休眠、引擎停止和离线追赶期间不显示旧状态。
iOS 在每次便意开始时只提醒一次：

- 前台使用已有应用内提示，点击回到设备页；同时播放约 0.55 秒的双音提示。无需系统通知权限，也不依赖免打扰或静音开关状态检测。
- 提示音尊重 App 的“声音”开关。短暂使用 `AVAudioSession.playback`，结束、切后台、音频中断或关闭 App 声音时恢复之前的音频配置；不覆盖画中画已接管的音频配置。媒体音量为零或音频不可用时仍可能无声。
- 后台仍发送一次系统通知；是否展示及响铃由系统权限、专注模式和静音设置决定。应用挂起后不能保证实时检测便意。
- 后台请求恰好在前台投递时转为应用内提醒，抑制系统横幅和系统声音，避免重复。

倒计时归零、状态不可用、暂停或关闭会话时移除通知及当前应用内提示。每次便意使用独立序号，延迟回调不会播放过期提示。

```bash

POCKET_MEETS_POTTY_FIXTURES="$PWD/../tama-private/potty-research" \
```

`potty_probe` 可从任意该版本存档采样，输出画面、SRAM、快照和状态；只写指定输出目录：

```bash
cargo run --release --example potty_probe -- \
  /path/to/sweets.bin /path/to/input.t18s \
  /path/to/new-output-dir 30 1 1
```

最后三个参数是模拟秒数、RTC 加速倍率、采样间隔。便意窗口必须以倍率 1 验证。
可用 `PROBE_PRESS=0.1:A,0.6:A` 安排按键，用 `PROBE_WATCH=1` 追踪参数区读取。
不要将输出目录设为输入存档所在的游戏存档目录。

限制：已实测当前成人存档；其他成长阶段使用同一字段，但尚未逐一做真实养育回放。
不同 ROM 版本不做推断性兼容。
