# Sweets v062 信息面板：隐藏字段与展示设计

## 睡眠读数保护（build 10029，2026-11-14）

- `Session::care_info` 与显示休眠状态使用同一个 `asleep()` 判断，覆盖 CPU 掉电和
  `alarm_wake`。分钟闹钟启动的冷启动会重建 SRAM，此时整份实时信息返回 `asleep`，
  不发布过渡参数；用户唤醒后重新读取，不缓存或推算旧倒计时。
- 只有阶段4且累计成长分钟至少2940、没有待处理进化事件，才显示“已成年”。
  阶段4但计时不足时显示成长时间暂不可用；待进化事件优先显示等待进化；未知阶段
  不默认成年。这是面板的保守有效性检查，不修改固件数据或成长规则。
- 真实 Sweets ROM 上，用成年存档副本构造阶段2/G100、阶段3/G1600的受控年轻角色，
  各回放120模拟秒，分别覆盖显示保持唤醒和允许掉电。四组均未出现阶段4读数；
  允许掉电时，分钟闹钟冷启动中观察到阶段0，随后恢复原年轻阶段。
  因而尚未复现用户实机的“睡觉显示已成年”，不能将闹钟重建断言为该现场的根因。
- 回归测试 `young_sleep_and_minute_alarm_never_report_mature` 在提供私有 ROM 与
  `POCKET_MEETS_POTTY_FIXTURES` 时执行真实固件，覆盖儿童/少年入睡及分钟闹钟，
  验证休眠不发布数据、可读年轻状态不显示成年。另覆盖成熟阈值、不一致读数、
  未知阶段、待进化事件和 CPU 醒着但仍处于闹钟唤醒的 API 状态。
  探针和输入副本位于 `../tama-private/young-sleep-research/`，不提交私有素材。

2026-11-13。目标为用户已指定的 JP v062 Sweets 固件，SHA-256

## 推荐首版字段

| 展示项 | 内部来源 | 展示方式与边界 |
| --- | --- | --- |
| 距下一次成长 | 累计成长分钟、阶段、进化事件位 | 显示“还需有效成长 X 小时 Y 分”，可配进度。成人阶段不设常规下一阶段倒计时。暂停、门控与补算会影响何时真正达到，不能换算成现实到点时间。 |
| 养育失误 | 当前保存的失误计数 | 显示次数；普通成长阶段保留。新生及部分特殊流程重置，不能称“本阶段失误”或永久终身累计。 |
| 饥饿呼叫忽视预算 | 饥饿呼叫事件及其倒计时 | 只有正在呼叫且剩余非零时显示“再忽视约 X 个固件分钟将记一次失误”；非活动状态显示“无待处理呼叫”，不能显示“0分钟即失误”。 |
| 心情呼叫忽视预算 | 心情呼叫事件及其倒计时 | 与饥饿呼叫独立；两者一起到期会记两次失误。 |
| 精确心情值 | 心情原始值、阶段上限 | 显示如“47 / 100”；阶段1..3上限30，成人上限100。相比固件进度条能看清小幅变化，不把所有阶段都按100计算。 |
| 距下次满腹度下降 | 当前满腹度、满腹度下降倒计时 | 有满腹度时显示当前倒计时；已为0时不伪造负值或下一格下降。读取角色当前保存的计时，不硬编码统一周期。 |
| 距下次心情下降 | 当前心情值、心情下降倒计时 | 该路径每次最多扣3，到0为止；当前为0时不再显示下降。门控可能暂停处理。 |
| 当前便意窗口 | 便意秒计数 | 出现便意后显示剩余1..20秒；无便意显示“暂无便意”。不把它称为距下次排便的预测。 |

满腹度的精确值为0..6，但固件已经按格显示，因此可作为倒计时的辅助文字，不必单独占一行。
地上便便数同理，不必在面板重复已有可见信息。

可选高级项：**疾病累计值及当前异常状态**。普通进化会清疾病累计，第5次疾病也清零并转入严重状态，因此不适合标为“总生病次数”。首版可以先不展示这个计数，避免增加解释负担。

## 字段布局和静态证据

参数区基址 `P = 0xF800D834`。下列值均只读。

| 偏移 / CPU 地址 | 类型 | 含义 | 主要证据 |
| --- | --- | --- | --- |
| `+0x05 / F800D839` | u8 | 满腹度0..6 | `20157304` 的进食增量路径，`20157384..88` 封顶6；`2015F8A0..D6` 状态页逐格绘制。 |
| `+0x08 / F800D83C` | u8 | 满腹度下降剩余分钟 | `20154A5C..6C` 减一，到0后 `20154A6E..7C` 扣满腹度；随后用角色表 `+0x14` 重装。 |
| `+0x09 / F800D83D` | u8 | 饥饿呼叫忽视剩余分钟 | `20153818..24` 初始化15；`20154AD8..EA` 减一，归零经 `20154BC8` 调用失误函数。 |
| `+0x0C / F800D840` | u32 LE | 固件事件位 | bit0为饥饿呼叫、bit1为心情呼叫、bit7为进化事件；需要与各自计时联合判断。 |
| `+0x11 / F800D845` | u8 | 精确心情值 | `2015725C` 加值，`201572AA..C4` 按阶段封顶30或100；`201572E4` 饱和扣减；`2015F840..` 状态页映射成分段进度条。 |
| `+0x12 / F800D846` | u8 | 心情下降剩余分钟 | `20154AEE..FE` 减一，到0经 `20154B08..0C` 扣3；角色表 `+0x15` 重装周期。 |
| `+0x13 / F800D847` | u8 | 心情呼叫忽视剩余分钟 | `2015379C..A8` 初始化15；`20154B38..4A` 减一，归零经 `20154C18` 调用失误函数。 |
| `+0x14 / F800D848` | u8 | 养育失误计数 | `20157178..80` 增一；两路忽视计时到期共同调用。第一代少年选择 `20133F7A..C8` 按0..2、3..5、6+分档，另结合心情。 |
| `+0x15 / F800D849` | u8 | 疾病累计值 | `20154318..2C` 增一，`2015434C..5C` 第5次清零并设置异常位；普通进化共用尾部 `20156ACE` 清零。 |
| `+0x16 / F800D84A` | u8 | 照顾/疾病相关状态位 | `2015430C` 疾病路径设置bit0，严重路径还设置bit2；成长函数在bit2置位时不加G。其他位未全面恢复语义，不作为通用健康百分比。 |
| `+0x1C / F800D850` | u32 LE | 累计成长分钟G | `20154758..5C` 自增；阶段1/2/3的普通阈值为累计60/1500/2940。详见成长报告。 |
| `+0x26 / F800D85A` | u16 LE | 当前便意倒计时 | 初始20，每秒减一；详见便意报告及自然回放。 |
| `+0x52 / F800D886` | u8 | 阶段，用于解释计数 | 阶段在界面中仅作为阈值和心情上限的上下文，不必重复列状态页信息。 |

### 失误与疾病的生命周期

- 普通进化函数 `20156A9C` 的1→2、2→3、3→4路径都返回同一尾部；清疾病累计 `+0x15`，不清失误 `+0x14`。这是静态路径结论，本轮没有执行完整进化动画。
- 新生初始化 `2015663C` 清成长分钟、显示年龄、失误、疾病累计和异常位；stage0孵化初始化也清失误。
- 另见特殊角色设置入口 `20131514`、`20131600`、`2014FBA0`、`20151F42` 清失误，尚未完整恢复这些入口的UI名称。
- 失误增一后达到255时，`201571D8..FC` 将其改写为3，所以这个保存值不是永久单调增长的历史审计。直接从非自然的原始255开始则u8加法可绕回0。
- 普通用药成功路径 `2015EF08` 清异常位，但不清疾病累计；疾病累计也不是当前一次患病时长。
- 常量传播和直接引用扫描有边界，不能证明不存在间接写入或整体存档重置。

## 面板约束

- 采用只读API，由代码指纹选择内存布局；不在查看信息时执行固件函数、推进模拟器或写RAM。
- 仅面板打开时约每秒更新一次；关闭后停止采样，不额外开启后台常驻任务。
- 未初始化、深睡导致SRAM失效、离线追赶、会话关闭或未知固件时，不把旧值显示成实时数值；可显示不可用，或明确带时间的上次有效快照。
- 成长时间按分钟展示，不拼凑伪精确的现实秒数。到达阈值且进化事件待处理时显示“等待进化流程”；计数已超过阈值但没有相应事件时不保证立即进化。
- 下降及忽视倒计时写“固件计时”，与App的暂停/追赶状态一起解释，不直接承诺现实截止时间。
- 先不显示预测进化角色/概率、总生病次数、死亡倒计时、总失误终身记录或固定下次排便时刻；这些语义或完整规则尚未验证。

相关证据：[成长分钟与阈值](age-growth-firmware-notes.md)、[年龄和暂停](sweets-age-and-pause.md)、[便意窗口](potty-sweets.md)。
